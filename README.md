## 三、配置参数怎么填：六项设置决定性能和账单

购买页里真正影响使用体验和费用的，是付费模式、地域、规格、镜像、存储和带宽这几项，逐项说清楚怎么选。

### 付费模式：长期用就选包年包月

三种模式：包年包月、按量付费、抢占式实例。包年包月适合长期业务，年付比月付优惠15%到40%；按量付费按实际用量结算，适合短期测试，用完即释放；抢占式实例价格最低，但资源可能被回收，只能跑可中断的任务。新手直接选包年包月，预算好算，运行也稳。

### 地域：选了就不能改

核心原则是离用户近：北方用户选北京、青岛，南方用户选杭州、上海、深圳，降低访问延迟。两个硬规则要记住：实例创建后地域不能更改；如果后面要和云数据库RDS等产品内网互通，必须选同一地域。阿里云目前在全球有29个地域、90个可用区。做跨境业务的可以选中国香港或新加坡，免备案直接上线。

### 实例规格：先小后大

个人博客、测试环境，1核2G或2核4G够用；企业网站和常规应用，4核8G或8核16G；高性能计算、大数据再往8核以上走。拿不准就先买低配，阿里云支持后续升级配置、补差价即可，服务不中断。

### 镜像与存储

镜像相当于装机盘。公共镜像是最干净的官方系统，Linux下Ubuntu适合建站和后端开发，需要.NET或SQL Server就选Windows Server；想省去手动配环境，选云市场镜像，LNMP、Docker、宝塔都能一键装好。存储上系统盘默认40G起步，装系统和基础软件够用，对IOPS敏感的应用再换更高性能的ESSD。建议把自动快照打开（约0.12元/GB/月），数据误删还有得救。

### 带宽：先勾公网IPv4，再谈大小

必须勾选“分配公网IPv4地址”，否则外面访问不到你的服务器。小型网站1到3M固定带宽足够（1M固定带宽约23元/月），视频类应用要5M以上；流量波动大的业务选按使用流量计费，约0.8元/GB，用多少付多少，而且流量计费模式下峰值可以拉得比较高，阿里云免费提供5Gbps的DDoS基础防护。

### 安全组和登录密码

安全组就是防火墙，基础使用开四个端口：Linux远程连接的22、Windows远程桌面的3389、网站HTTP的80和HTTPS的443，其他端口按需再放行，开得越少越安全。实例创建后，建议把22端口的授权对象收紧到自己的IP。登录凭证推荐自定义密码，需包含大小写字母、数字和特殊字符；Linux实例用ecs-user登录比root安全，需要权限时用sudo提权，Windows默认administrator。密码忘了可以在控制台重置，不至于把自己锁在门外。

## 七、几个高频问题

**内地服务器不做备案能用吗？**
买服务器本身不需要备案，但中国内地的实例要对外做网站，必须完成ICP备案，而且租用时长满3个月才能提交备案申请，未备案的网站无法公开访问。不想备案就用香港或新加坡地域。

**买完之后怎么登录？**
控制台里可以直接远程连接；习惯用工具的话，Linux用XShell、Putty连22端口，Windows用远程桌面连3389端口。第一次登录先检查安全组端口是否生效，免得连不上干着急。

**到期不续费会怎样？**
实例到期后会停机，逾期不续可能无法再按优惠价续费，严重的实例会被释放、数据清空。自动续费和到期前7到15天手动续费，都是为了避开这个坑。

**个人认证能买199元的u1吗？**
不能。u1是企业实名认证独享，个人账号选经济型e或轻量应用服务器，相近配置下更划算。

**月付中途不想要了能退吗？**
能，按比例退款：订单原价减去已使用天数乘以日价，具体金额以控制台显示为准。
